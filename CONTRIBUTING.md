# Contribution Guidelines

Thanks for helping keep this list accurate.

## Adding an entry

- The project must be a real, usable AI coding agent or something directly supporting one: a harness, an SDK, a benchmark, or a guide. A waitlist page or an announcement with nothing to install does not count.
- Link to the official site or the canonical repository, not a blog post, a review site, or an affiliate link.
- The project must be actively maintained. A repository with no commits in the last 12 months is not accepted.
- Use this format and keep the section in alphabetical order:

  `- [Name](https://link) - One sentence description ending in a period.`

- Do not start the description with the project's own name, and do not use marketing language. Say what the tool does.
- One project per pull request, unless the PR updates a whole section.

## Updating an entry

Projects get renamed, acquired, archived, and redirected all the time. If a link moved, a project was abandoned, or a description no longer matches what the tool does, open a pull request with the link that shows the change.

## Removing an entry

Open a pull request that removes the entry and says why: the repository was archived, the product shut down, the link is dead, or the project no longer fits the topic.
